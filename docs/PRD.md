# 線上算命系統 - 產品需求文件 (PRD)

## 1. 專案概述
- **專案名稱**：線上算命系統
- **專案描述**：一個提供使用者線上算命、占卜與抽籤的互動平台，並結合靈籤紀錄與線上捐獻「香油錢」的功能，為現代人提供即時、便利的心靈指引服務。
- **背景與動機**：現代人生活節奏快、壓力大，面對事業、感情等人生抉擇時常需要心靈寄託。然而，前往實體廟宇或算命館可能受限於時間與空間。將傳統的求神問卜轉移至線上，除了能讓使用者隨時隨地尋求指引外，也能延續傳統文化中「還願、添香油錢」的習俗。
- **目標用戶**：
  1. 對命理、星座、紫微、八字或傳統民間信仰感興趣的社會大眾。
  2. 面臨生活、感情、工作抉擇，需要簡單指引與心靈慰藉的年輕人至中高齡使用者。
- **核心價值主張**：以簡潔直覺的操作介面，提供隨手可得的傳統占卜體驗；完整保留「求籤、解籤、留紀錄、添香油錢」的服務閉環。

## 2. 功能需求

以下列出系統的 5 項主要功能與對應的使用者故事：

1. **算命、占卜、抽籤功能**
   - **使用者故事**：作為一名 **尋求指引的使用者**，我希望能夠 **進行線上抽籤或占卜（例如求觀音靈籤、塔羅牌抽牌等）**，以便 **在迷惘時獲得方向上的提示與解答**。

2. **儲存算命結果與歷史紀錄**
   - **使用者故事**：作為一名 **會員使用者**，我希望能夠 **將每次抽到的籤詩或占卜結果儲存起來**，以便 **日後可以回顧自己過去的運勢狀況，驗證準確度**。

3. **捐香油錢（線上添香油 / 樂捐）**
   - **使用者故事**：作為一名 **還願或表達感謝的使用者**，我希望能夠 **透過線上支付的方式捐贈香油錢**，以便 **表達對神明保佑的謝意與支持平台營運**。

4. **會員註冊與登入系統**
   - **使用者故事**：作為一名 **新使用者**，我希望能夠 **註冊一組自己的帳號密碼並進行登入**，以便 **妥善並私密地保管我的算命紀錄與捐獻履歷**。

5. **社群分享功能**
   - **使用者故事**：作為一名 **抽到上上籤的使用者**，我希望能夠 **一鍵將算命或抽籤的吉利結果分享至社群媒體（如 LINE、FB 或 IG）**，以便 **與親友分享好運與喜悅**。

## 3. 非功能需求

- **技術限制**：
  - 系統後端框架需使用 **Flask** 開發。
  - 前端頁面渲染需依賴 **Jinja2** 模板引擎，並搭配 Vanilla CSS / JavaScript。
  - 資料庫使用輕量級的 **SQLite** 進行本地資料存儲。
- **效能與安全考量**：
  - **資料隱私**：帳號密碼需進行雜湊加密存儲，且使用者只能看到自己的算命結果。
  - **金流安全**：「捐香油錢」若涉及真實金流串接，需透過安全合規的第三方支付（如綠界或 Line Pay），過程中避免直接儲存使用者信用卡資訊（MVP 初期可採模擬付款）。
  - **防刷機制**：為避免資源浪費，針對短時間內頻繁進行算命抽籤的行為可建立簡單的防機器人機制（如 Rate Limiting）。

## 4. MVP 範圍 (Minimum Viable Product)

| 優先級 | 範圍定義 | 功能項目 |
| :---: | :--- | :--- |
| **Must Have**<br>(必須擁有) | 系統核心體驗，讓使用者可以完整走完核心流程 | - 首頁引導<br>- 線上抽籤/占卜系統<br>- 顯示解籤結果<br>- 簡單的「捐香油錢」前台頁面（模擬付款） |
| **Should Have**<br>(應該擁有) | 強化留存率的基礎建設 | - 會員註冊 / 登入功能<br>- 個人的「歷史算命/抽籤紀錄」查詢 |
| **Nice to Have**<br>(有了更好) | 優化體驗的加分項目 | - 分享結果到社群平台的圖文產生器<br>- 串接真實第三方支付（綠界/Line Pay）以實現真實香油錢捐贈<br>- 更豐富的占卜種類（紫微、八字、塔羅） |
